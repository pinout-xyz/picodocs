# PicoDocs

PicoDocs is nothing more than the Raspberry Pi Pico SDK docs, generated from the SDK tooling, in their original, unadulterated form and presented on https://picodocs.pinout.xyz with a couple of monkey-patches to fix the search box, swap out the trademarked Pi logo and give you a nav between SDK versions and targets.

Shout here if the site is broken or needs a bump to accomodate a new SDK version, otherwise see: https://github.com/raspberrypi/pico-sdk

## Why?

I don't like the presentation of official documentation. Simple!

It:

1. Has a broken search box, preferring unrelated guff over SDK functions. Yes you can Ctrl + F, but the result is not very friendly or useful.
2. Has a continuous scrolling page which immediately gets you lost. Where does your desired section start, where does it end? Who knows!
3. Has a theme with very little visual differentiation between sections, confounding no 2. Where does a section start, WHERE!!?!? AAAARRGHH!
4. Cannot, as a consequence of 2 and 3, be feasibly deep-linked. Sorry did you sneeze? Yeah you've lost your place.
5. Is mixed with a bunch of other content, in which I am thoroughly uninterested when trying to consult the documentation.

More often than not I abandon the docs or consult the SDK source directly. This is my safe space! I hope it can be yours too.
